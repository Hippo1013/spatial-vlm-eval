# MSMU Judge 提示词中文参考

> 本文档仅供人工阅读，不会被 scorer 加载，也不是 canonical protocol 的替代品。
> 实际运行时提示词以
> `src/spatial_vlm_eval/benchmarks/msmu/scorer.py` 中的英文源码为唯一真值。
> JSON 字段名保持英文，因为 scorer 会按这些字段解析 judge 响应。

judge 不接收图片，只接收以下三段文本：

- `Question`：清理后的原始问题；
- `Answer`：reference 标准答案；
- `Response`：被测模型生成的 prediction。

当前 scorer 根据任务类型选择以下四套提示词。

## 1. 数值、距离和数量等任务

```text
你需要根据问题和正确答案，帮助我评估给出的回答。

你需要把正确答案和回答中的测量值转换成米。换算关系如下：
1 英寸 = 0.0254 米
1 英尺 = 0.3048 米
1 厘米（cm）= 0.01 米

你需要输出两个以米为单位的浮点数：一个对应正确答案，另一个对应回答。
如果正确答案或回答包含多个数值，则应输出包含这些数值的列表。

输出必须采用 JSON 格式。


示例 1：
问题：与交叉桌相对的棕色长桌有多高？
正确答案：与交叉桌相对的棕色长桌高度为 1.02 米。
回答：它有 2.17 米宽。
输出：
"answer_in_meters": 1.02, "response_in_meters": 2.17

示例 2：
问题：图中椅子的总数是多少？
正确答案：2。
回答：有 2 把椅子。
输出：
"answer_in_meters": 2, "response_in_meters": 2

示例 3：
问题：深色枕头的尺寸是多少？
正确答案：深色枕头的尺寸为 0.8 米 × 0.63 米 × 0.55 米。
回答：它有 35.9 英寸宽。
输出：
"answer_in_meters": [0.78,0.63,0.55],
"response_in_meters": 0.91

示例 4：
问题：床的高度是 0.81 米，那么桌子和床头柜的高度分别是多少？
正确答案：已知床高 0.81 米，我认为桌子的高度是 1.02 米，床头柜的高度是 0.93 米。
回答：已知床高 0.81 米，我认为桌子的高度是 1.36 米，床头柜的高度是 0.77 米。
输出：
"answer_in_meters": [1.02,0.93],
"response_in_meters": [1.36,0.77]


现在轮到你：

问题：{question}
正确答案：{answer}
回答：{pred}

只返回一个 JSON 对象，且必须包含以下字段：
"answer_in_meters"
"response_in_meters"
```

注意：英文源码示例 3 的正确答案文字是 `0.8`，示例 JSON 却写成了 `0.78`。本文档忠实保留该
现有不一致，不对运行时提示词作修正。

## 2. 定性判断任务

```text
你需要根据问题和正确答案，帮助我评估给出的回答。

为了给回答打分，你应输出一个 0 到 1 之间的整数。

1 表示回答与正确答案完全匹配。
0 表示回答与正确答案完全不同。

输出必须采用 JSON 格式。


示例 1：
问题：从观察者视角看，蓝色床是否位于窗帘左侧？
正确答案：是的，床位于窗帘左侧。
回答：是的，蓝色床位于窗帘左边。
输出：
"your_mark": 1

示例 2：
问题：木桌和黑色椅子之间，哪一个更高？
正确答案：木桌更高。
回答：椅子。
输出：
"your_mark": 0

示例 3：
问题：桌子、椅子和窗帘之中，哪个最高？
正确答案：窗帘最高。
回答：窗帘。
输出：
"your_mark": 1


现在轮到你：

问题：{question}
正确答案：{answer}
回答：{pred}

只返回一个包含 "your_mark" 字段的 JSON 对象。
```

## 3. 根据物体提取坐标

```text
你需要帮助我评估一个视觉定位回答。

问题要求给出某个物体在图像中的归一化坐标。
这些坐标已经是归一化图像坐标，不是以米为单位的测量值。

只从正确答案和回答中提取问题所要求的坐标对。

只返回包含以下字段的 JSON：
{
  "answer_coordinates": [数值, ...],
  "response_coordinates": [数值, ...]
}


示例 1：
问题：黑色电视的坐标是什么？
正确答案：(0.72,0.28)。
回答：(0.64,0.13)。
输出：
{
  "answer_coordinates": [0.72,0.28],
  "response_coordinates": [0.64,0.13]
}

示例 2：
问题：瓷质马桶的坐标是什么？
正确答案：它位于图像中的 (0.58,0.41)。
回答：马桶大约位于 (0.58,0.26)。
输出：
{
  "answer_coordinates": [0.58,0.41],
  "response_coordinates": [0.58,0.26]
}

如果任意一方不包含可用坐标，则该方返回空列表。


现在轮到你：

问题：{question}
正确答案：{answer}
回答：{pred}

只返回 JSON 对象。
```

## 4. 根据坐标判断物体

```text
你需要帮助我评估一个视觉定位回答。

问题给出一个归一化图像坐标，并询问该坐标处是什么物体。
请比较回答中提到的物体与正确答案中提到的物体。

只有当回答指向与正确答案相同的物体时，才标记为 1。

无关紧要的冠词、标点符号以及轻微的同义改写可以接受。
如果颜色不同、物体类别不同，或者指向不同的物体实例，则应标记为 0。

只返回包含以下字段的 JSON：
{
  "answer_object": "...",
  "response_object": "...",
  "your_mark": 0或1
}


示例 1：
问题：坐标 (0.97,0.6) 处是什么物体？
正确答案：棕色柜子。
回答：棕色木柜。
输出：
{
  "answer_object": "brown cabinet",
  "response_object": "brown wooden cabinet",
  "your_mark": 1
}

示例 2：
问题：在坐标 (0.31,0.96) 处可以找到什么？
正确答案：深色椅子。
回答：棕色椅子。
输出：
{
  "answer_object": "dark chair",
  "response_object": "brown chair",
  "your_mark": 0
}

示例 3：
问题：位置 (0.42,0.72) 属于什么物体？
正确答案：桌子。
回答：桌子。
输出：
{
  "answer_object": "table",
  "response_object": "table",
  "your_mark": 1
}


现在轮到你：

问题：{question}
正确答案：{answer}
回答：{pred}

只返回 JSON 对象。
```

前两套提示词分别用于数值提取和定性判分。grounding 被拆分为后两套提示词，避免把归一化图像
坐标误当成米制测量值。
